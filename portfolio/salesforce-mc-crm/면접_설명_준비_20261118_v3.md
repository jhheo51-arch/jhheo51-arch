# 정기 점검 A/B 사례 면접 설명 준비

## 문제 정의

이 문서는 본인이 [검토표](./본인_검토_20261118_v3.md)의 방향 여섯 가지를 고른 뒤 수정한 **연습용 대본**입니다. 아래 문장을 본인 단독 실행 경험으로 말하면 안 됩니다. 실제로 한 일은 A/B 방법론 전자책 작성과 포트폴리오의 AI 협업 합성 실습 검토입니다. 실제 OEM 캠페인, MC 발송, 서비스센터 운영은 하지 않았습니다. 30일 대상 창과 28일 관측 기간은 교육용 가정이며 현장 근거는 없습니다.

## 문제 해결: 말하는 구조

**30초 초안.** “저는 예약 클릭보다 실제 방문 완료를 성과로 보는 사례를 골랐습니다. 가상 정기 점검 안내에서 관리 필요성 A와 예약 편의 B를 비교했습니다. 동의와 필수 고지 조건을 확인한 경우에만 선택적 안내 미발송 H를 제한적으로 두는 설계입니다. 교육용 28일 관측에서 B가 A보다 방문 완료율이 1.09%p 높았지만, 수신 철회 위험과 센터 수용량을 확인하지 못해 전면 적용은 보류했습니다. 이 수치는 AI와 함께 만든 합성 실습 결과입니다.”

**90초 초안.** “CRM 캠페인에서 예약 클릭은 중간 행동이고 실제 서비스 방문이 최종 행동에 가깝다고 판단해, 방문 완료를 성과로 보는 사례를 골랐습니다. 가상 OEM의 정기 점검 대상 중 동의가 있고 아직 예약하지 않은 차주를 대상으로, 차량 관리 필요성을 알리는 A와 예약 편의를 강조하는 B를 비교했습니다. 선택적 안내를 보내지 않는 H는 동의와 필수 고지 의무를 확인한 뒤에만 제한적으로 운영하는 설정입니다. 30일 대상 조건과 28일 관측 기간은 교육용 가정으로 두고, 실제라면 예약과 방문 원장으로 다시 정하겠습니다. 처음 배정된 고객 전체를 분모로 둔 합성 자료에서 A는 9.15%, B는 10.24%로 B가 1.09%p 높았습니다. 그러나 수신 철회 악화 가능성, 센터 수용량과 비용 자료가 없으므로 전면 적용을 보류했습니다. +0.5%p 개선과 +0.2%p 수신 철회 악화 허용도 교육용 예시이며 실제 기준은 현장에서 합의해야 합니다. 자료를 확인한 뒤 제한적 적용 여부를 재검토하겠습니다. 실제 MC에서 캠페인을 운영한 결과는 아닙니다.”

본인은 핵심 문제, A/B 비교 가설, 교육용 기준의 처리 방식, 기간 가정의 취급, H의 조건부 운영과 전면 적용 보류를 선택했습니다. 아래 답변 중 실제 기간, 운영 허용 여부와 메시지 문안은 **미확정**입니다.

| 예상 질문 | 답변 초안과 확인할 부분 |
|---|---|
| 왜 시승이 아닌 정기 점검입니까? | 기존 전자책 v0.10은 시승을 다룹니다. 포트폴리오에서는 Aurora의 차주 서비스 기록과 이어지는 질문을 보여 주려고 정기 점검을 별도 합성 사례로 잡았습니다. 이 이유가 본인의 의도와 일치하는지 확인해야 합니다. |
| 왜 예약 클릭이 아니라 방문 완료입니까? | 본인이 예약 클릭보다 실제 방문 완료를 높이는 방법을 핵심 문제로 선택했습니다. 메시지에 반응한 것과 서비스를 이용한 것은 다릅니다. 예약과 클릭은 중간 지표로 두되, 센터가 만석이면 방문 완료가 메시지 효과를 충분히 반영하지 못할 수 있습니다. |
| 왜 30일 이내 대상과 28일 관측입니까? | 본인은 두 기간을 교육용 가정으로 유지하기로 했습니다. 실제 차주의 예약 리드타임이나 정비 주기에서 추정한 값이 아닙니다. 실제 실행 전에는 예약과 방문 원장 분포, 센터별 수용량으로 다시 정해야 합니다. |
| H에는 위험한 안내도 보내지 않았습니까? | H에 보내지 않는 것은 이 실험의 선택적 마케팅 안내뿐입니다. 본인은 동의 범위와 법적 의무를 확인한 경우에만 H를 제한적으로 운영하기로 했습니다. 안전 고지와 법적 의무 안내는 실험 외부에서 모든 군에 정상 처리해야 합니다. |
| B가 앞선 뒤에는 무엇을 합니까? | 본인은 전면 적용을 보류하고 수신 철회, 비용과 센터 수용량 자료를 확인한 뒤 제한적 적용 여부를 재검토하기로 했습니다. 제한적 적용을 이미 승인한 것은 아닙니다. |
| 왜 열어 본 고객만 계산하지 않습니까? | 열람 여부는 배정 이후 행동입니다. 그 사람만 분모에 남기면 처음 배정된 군의 비교가 깨질 수 있어, 적격 판정 후 배정된 사람 전체를 분석합니다. |
| +1.09%p면 충분히 이긴 것 아닙니까? | 합성 모형의 관측 차이는 B에 유리하지만, 예시 사업 기준 +0.5%p를 확실히 넘는다고 말하기에는 구간 하한이 +0.29%p입니다. 통계적 차이와 확대 승인 결정을 분리합니다. |
| p값이 작으면 바로 발송해야 하지 않습니까? | p값은 비용, 수신 철회, 서비스센터 수용량을 판단하지 않습니다. 또한 이 데이터는 의도한 확률에서 만든 합성 예시여서 현실의 효과를 입증하지 않습니다. |
| +0.5%p와 +0.2%p의 근거는 무엇입니까? | 실제 사업 근거가 없습니다. AI가 합성 자료 생성 전에 둔 예시값이고, 본인이 교육용 예시로만 유지하기로 했습니다. 실제 기준은 방문당 가치, 메시지 비용, 센터 수용량과 고객 보호 원칙을 현장에서 합의해야 합니다. |
| 수신 철회 차이 +0.058%p는 작은데 왜 보류합니까? | 탐색 구간 상한은 +0.26%p라 교육용 허용 악화 +0.2%p를 넘는 위험을 배제하지 못합니다. 이는 정식 안전성 입증도 아니어서 추가 관측이나 중단 기준이 필요합니다. |
| MC에서 실제로 무엇을 했습니까? | 이 A/B 사례는 MC에서 실행하지 않았습니다. MC 관련 본인 작성 과제는 Open Rate, Not Sent, 접속 로그와 Contact 관리 문제의 운영 방안입니다. 실제 계정 설정과 발송 기록은 없습니다. |
| AI는 어떤 부분을 도왔습니까? | 정기 점검 시나리오의 합성 계획, 원장, 계산 코드와 초안 문장을 AI 협업으로 만들었습니다. 본인이 승인하지 않은 이유와 기준을 본인 판단처럼 말하지 않습니다. 검토 후에는 본인이 선택한 문제, 결론과 수정 이유만 자신의 판단으로 설명합니다. |

## 결과 검토

**지금 답할 수 있는 것.** 합성 자료의 대상 규칙, 배정군, 분모, 28일 관측, 산식, 결과의 사용 제한은 공개 원장과 코드로 대조할 수 있습니다.

**사용 제한.** 본인이 고른 방향은 여섯 가지입니다. 이 선택이 실제 차주 행동의 원인을 확인했다는 뜻은 아닙니다. 30일 적격 창과 28일 관측 기간의 현장 적합성, H군의 실제 운영 허용 여부와 메시지 문안은 추가 검토가 필요합니다. 위 답변은 합성 자료를 설명하는 연습 대본이지 본인의 실무 이력 증명서가 아닙니다.
