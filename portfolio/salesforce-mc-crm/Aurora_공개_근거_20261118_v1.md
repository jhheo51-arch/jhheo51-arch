# Aurora Owners 360에서 확인할 공개 근거

2026-11-18. 계정 로그인 없이 확인할 수 있는 저장소 자료를 포트폴리오의 주장별로 연결합니다. 문서와 코드의 존재가 실제 고객센터 성과를 뜻하지는 않습니다.

| 포트폴리오 주장 | 공개 자료 | 확인 범위 |
|---|---|---|
| 차주, 차량, 보증과 VOC를 연결한 모델 | [README](https://github.com/jhheo51-arch/aurora-owners-360), [PRD](https://github.com/jhheo51-arch/aurora-owners-360/blob/main/docs/PRD.md) | 설계 의도와 구현 범위 |
| 안전 VOC의 응답 기한과 이관 | [Flow 소스](https://github.com/jhheo51-arch/aurora-owners-360/blob/main/force-app/main/default/flows/VOC_Case_Before_Save.flow-meta.xml), [PRD의 T4 수용 테스트](https://github.com/jhheo51-arch/aurora-owners-360/blob/main/docs/PRD.md) | 저장 시점의 규칙과 개발 org에서 기록한 기대값 및 조회 결과 |
| 팀장 정보 누락 시 저장 차단 | [Flow 소스](https://github.com/jhheo51-arch/aurora-owners-360/blob/main/force-app/main/default/flows/VOC_Case_Before_Save.flow-meta.xml), [PRD의 T8 수용 테스트](https://github.com/jhheo51-arch/aurora-owners-360/blob/main/docs/PRD.md) | 예외 규칙과 개발 org 수용 테스트 기록 |
| 상담 화면 | [README의 화면 링크](https://github.com/jhheo51-arch/aurora-owners-360/blob/main/README.md) | 공개 화면 자료의 위치. 화면만으로 실제 운영 결과를 입증할 수 없음 |

**사용 제한.** 공개 PRD의 개발 org 기록을 대조했습니다. 현재 org의 상태, 새 org 설치, 실제 권한, 상담원의 첫 응답 시간은 이 자료로 검증되지 않습니다. 이 범위를 넘어 주장할 필요가 생기면 계정 로그인 후 별도 확인합니다. 지금의 포트폴리오 근거에는 공개 자료로 충분하므로 로그인은 요청하지 않습니다.

**앞으로 추진.** 먼저 새 org 설치와 직원 권한을 검증합니다. 그다음 익명 시험 VOC로 접수, 이관, 첫 응답 시각을 연결하고 기한 준수 여부를 계산합니다. 완료 기준은 설정 화면, 시험 입력, 기대 결과와 실제 조회값입니다.
