# 허재혁 | 서비스 기획, 마케팅 기획

고객이 어디서 멈추는지 근거로 찾고, 누구에게 무엇을 먼저 할지 기준과 함께 정합니다. 정한 기준은 화면, 시제품과 캠페인 설계로 옮겨 그 판단이 맞았는지 다시 잽니다.

공개 자료에서 확인한 사실, 제가 세운 가정과 아직 검증하지 못한 효과를 구분해 기록합니다.

## 작업하는 방식

- **문제부터 정리합니다.** 누가 어떤 순간에 막히는지와 무엇이 달라져야 하는지를 먼저 적습니다.
- **선택의 이유를 남깁니다.** 기능과 지표를 나열하는 데서 그치지 않고 우선순위, 제외한 범위와 판단 조건을 설명합니다.
- **작동하는 결과물로 확인합니다.** 기획을 화면, 운영표와 계산 코드로 옮기고 입력을 바꿨을 때의 동작을 검사합니다.
- **결과의 한계를 구분합니다.** 자동 검사, 가상 자료의 계산과 실제 이용자 효과를 같은 성과로 취급하지 않습니다.

## 프로젝트를 볼 때

웹 서비스에서는 직접 작성과 AI 보조의 역할, 저장 실패와 오류 이후의 흐름을 중점적으로 봤습니다. 운영 프로젝트에서는 담당자, 기한, 다음 행동과 완료 기준이 이어지는지를 확인했습니다. 데이터 분석에서는 출처, 기간, 분모와 표본 수를 결과와 함께 적었습니다.

코드 작성과 조사, 검사를 보조하는 도구로 Codex와 Claude Code를 사용합니다. 프로젝트의 문제, 기능 범위와 최종 판단은 제가 정하고 결과를 검토합니다. 가상 고객과 시제품의 결과를 실제 회사의 운영 경험이나 성과로 제시하지 않습니다.
