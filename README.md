# 허재혁

### 제품 기획, 고객 경험, 데이터 실험

저장한 기록을 다시 쓰는 서비스, 고객 불편의 개선 순서를 찾는 도구, 공개 자료로 다음 행동을 검토하는 실험을 만듭니다.

- **최근 작업:** [MEMOIVE](https://github.com/jhheo51-arch/memoive), [새록이](https://github.com/jhheo51-arch/saeroki), [VoC Lens](https://github.com/jhheo51-arch/VoC-Lens), [CRM LOOP](https://github.com/jhheo51-arch/crm-loop), [Trend to Trust](https://github.com/jhheo51-arch/trend-to-trust)
- **작업 기록:** [전체 프로젝트와 실험](./portfolio/project-index/README.md)
- **다른 자료:** [직무별 이력서와 포트폴리오](./portfolio/other-roles/README.md)

[![지금까지 자란 새록이 묘목](https://raw.githubusercontent.com/jhheo51-arch/saeroki/main/assets/saeroki-tree.svg)](https://github.com/jhheo51-arch/saeroki)

새록이 묘목은 공개 저장소의 방문 합계, 스타, 작업량으로 자랍니다. 집계 기준과 확인 범위는 [새록이 저장소](https://github.com/jhheo51-arch/saeroki#성장-점수)에 적었습니다.

**일하는 방식:** 문제를 좁히고 판단 기준을 정한 뒤, 작게 만들어 확인합니다. 공개 자료 분석, 가상 구현, 합성 실습과 실제 결과는 구분해 기록합니다.

MC 및 CRM 포트폴리오는 현재 텍스트 초안입니다. 완성 PDF와 웹 원본은 공개되지 않았습니다.
