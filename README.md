# 허재혁 | Product & Operations

복잡한 운영 문제를 기준과 데이터로 정리하고, 실제로 작동하는 도구를 만듭니다.

## 잘하는 일

- 요청을 그대로 옮기기보다 실제로 막히는 지점을 찾아 문제를 다시 정의합니다.
- 공개 자료·가정·아직 확인하지 못한 내용을 구분하고, 판단에 필요한 지표와 우선순위를 세웁니다.
- 기획서를 웹 서비스·운영표·자동검사로 옮기고, 확인한 결과와 한계를 함께 남깁니다.
