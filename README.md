# 허재혁 | Product & Operations

복잡한 운영 문제를 기준과 데이터로 정리하고, 실제로 작동하는 도구를 만듭니다.

## 잘하는 일

- 흩어진 업무를 단계/담당자/완료 기준이 보이는 운영 흐름으로 정리합니다.
- 공개 자료와 가상 자료를 구분하고, 판단에 필요한 지표와 다음 행동을 설계합니다.
- 기획서에서 끝내지 않고 웹 화면/운영표/자동검사로 직접 작동하게 만듭니다.

## 대표 프로젝트

| 프로젝트 | 해결한 문제 | 결과물 |

| [MEMOIVE](https://github.com/jhheo51-arch/memoive) | 저장한 자료가 다시 쓰이지 못하고 쌓이는 문제 | 생각·출처·글쓰기를 연결한 AI 기록 서비스 |
| [Global CRM Event Operations](https://github.com/jhheo51-arch/global-crm-event-operations) | VIP 행사 전후 고객 정보와 후속 업무가 끊기는 문제 | 고객 여정·담당자·기한을 연결한 CRM 운영안 |
| [Seller Ready Board](https://github.com/jhheo51-arch/baemin-store-seller-ready-board) | 셀러 온보딩에서 지연·오류·담당자 누락을 찾기 어려운 문제 | 우선 신호와 다음 행동을 보여주는 운영 보드 |
