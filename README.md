# Heo Jae Hyeok | 근거를 다음 행동으로

## 소개

마케팅에서 시작한 관심을 이해관계, 시스템과 운영의 문제로 넓혀 왔습니다.

> **[CRM/SFMC&nbsp;웹&nbsp;포트폴리오&nbsp;↗](https://jhheo51-arch.github.io/jhheo51-arch/)** &ensp; **[커리어&nbsp;플로우](https://jhheo51-arch.github.io/jhheo51-arch/career-flow.html)**

**1. 시장과 고객:** 경영학 마케팅 트랙, 고객 가치와 시장 흐름 탐구<br>
**2. 관계와 맥락:** 정치외교학 복수전공, 이해관계자 관점 연구<br>
**3. 시스템과 운영:** 정보통신 장교, 시스템 연결과 인사 기록 대조<br>
**4. 고객 연결:** 인턴 경험, 웹 입력을 Salesforce Lead로 연결한 PoC<br>
**5. 제작과 실험:** 서비스/CRM, 운영 도구, 콘텐츠와 데이터 실험

**독립 프로젝트 47개** (공개 16개, 비공개 31개, 기획 단계 포함, 2026.11. 기준)

**일하는 방식:** 막힌 지점을 찾고 성공 기준을 세웁니다. 기록과 운영 조건으로 가설을 좁혀 작게 시험하고, 다음 행동과 멈출 기준을 함께 남깁니다.

**문제 정의 → 가설 → 반례 탐색 → 검증 → 판단**
